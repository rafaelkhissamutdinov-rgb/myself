# Цитата дня

Статическая страница: часы, дата, приветствие по времени суток («Доброе утро, Дарина»), предсказание на сегодня и под ним цитата Булгакова, Чехова или Достоевского. Каждый день новые обои (16 пастельных тем: персиковая, вишнёвая, радужная, небесная, солнечная и другие). Кнопка «Другая цитата» показывает новую пару «предсказание + цитата».

Сборки нет: достаточно открыть `index.html` или выложить папку на любой статический хостинг (например, GitHub Pages).

## Как выбирается день

- Номер дня берётся по локальной дате. Обои, предсказание и цитата выбираются из списков, перемешанных с фиксированным зерном, поэтому в один день у всех одно и то же.
- У каждой цитаты есть настроение: `warm` (тёплое), `light` (с улыбкой), `dream` (мечтательное) или `sigh` (лёгкое «ой, вот так-то»). Каждые обои подходят к одному-двум настроениям, и цитата дня выбирается под них.
- В полночь страница сама переключается на новый день.

Параметры адреса:

- `?name=Имя` — другое имя в приветствии (по умолчанию Дарина);
- `?day=2026-12-31` — посмотреть, что выпадет в указанный день;
- `?theme=peach` — посмотреть конкретные обои (id тем перечислены в `themes.js`).

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html`, `style.css`, `app.js` | страница, оформление, логика |
| `themes.js` | 16 тем обоев и SVG-рисунки (фрукты, цветы, облака…) |
| `data/quotes.js` | 171 цитата: Чехов 73, Булгаков 52, Достоевский 46 |
| `data/predictions.js` | 130 предсказаний (авторские, написаны для сайта) |
| `fonts/` | Cormorant Garamond, Manrope, Marck Script (лицензия SIL OFL, файлы лицензий рядом) |
| `tools/` | скрипты, которые проверяли цитаты |

## Как проверялись цитаты

Цитаты берутся на языке оригинала. Каждая из них найдена дословно в полном тексте произведения: при сравнении игнорируются только регистр, ё/е, пунктуация и пробелы. В `data/quotes.js` записан текст из самого источника. Пропуск внутри цитаты помечен «(…)». Говорящий в пьесах определён по разметке пьесы, в «Бедных людях» — по тому, кто пишет письмо.

Использованные тексты:

- [nevmenandr/word2vec-russian-novels](https://github.com/nevmenandr/word2vec-russian-novels) — «Мастер и Маргарита», «Преступление и наказание», «Палата № 6»;
- [JoannaBy/RussianNovels](https://github.com/JoannaBy/RussianNovels) — «Белая гвардия», «Театральный роман», «Братья Карамазовы», «Идиот», «Бесы», «Бедные люди», сборник рассказов Чехова («Дама с собачкой», «Ионыч», «Случай из практики» и др.);
- [dracor-org/rusdracor](https://github.com/dracor-org/rusdracor) — пьесы Чехова и Булгакова (TEI).

Как перепроверить:

```bash
cd tools
mkdir -p src && cd src
git clone --depth 1 https://github.com/nevmenandr/word2vec-russian-novels w2v
git clone --depth 1 https://github.com/JoannaBy/RussianNovels rn
git clone --depth 1 https://github.com/dracor-org/rusdracor rusdracor
cd ..
python3 build_quotes.py ../data/quotes.js   # упадёт, если хоть одна цитата не найдена
```

Новые цитаты добавляются в `tools/candidates.py`, после чего нужно запустить скрипт ещё раз.

Цитат из писем и записных книжек здесь нет: полных текстов писем в открытом доступе не нашлось, а проверить такие цитаты было не по чему.
